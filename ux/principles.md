# Press UI principles

- Start with the user's task, visible object, decision information, and exact result.
- Spend primary emphasis once in each decision area.
- Keep filtering, selection, estimates, and conversion scope truthful to one another.
- Prefer one alignment spine, repeated information lanes, and fewer containers.
- Keep the primary action visible at minimum, default, and wide window sizes.
- Preserve keyboard access, focus visibility, loading, failure, and recovery states.
- Use sentence case, semantic theme colors, native controls, and labels that predict results.
- Treat maintainer decisions in `decisions.jsonl` as taste constraints, not universal laws.
- Accept a change only from real-window evidence; source inspection alone is not visual proof.
